# Plantillas PDF

Coloca aquí **`EX10_template.pdf`** (formulario EX-10 oficial o plantilla AcroForm).

## Desarrollo rápido

Genera una plantilla placeholder (coordenadas de prueba):

```bash
npm run pdf:template
```

En producción, **sustituye** `EX10_template.pdf` por el PDF oficial del ministerio.
